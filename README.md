# 🎯 ST Landing Page v2

Landing page for **Szkoła Talentów**, a private math coaching school.  
Version 2 of the website focuses on improved performance, cleaner layout, and easier content management through Netlify CMS.

---

## 🚀 Live Demo
🔗 [szkolatalentow.com.pl](https://szkolatalentow.com.pl)

---

## 🧰 Tech Stack
| Area | Technology |
|------|-------------|
| Framework | [Gatsby v3.8.1](https://www.gatsbyjs.com/) |
| Styling | SCSS |
| CMS | [Netlify CMS](https://www.netlifycms.org/) |
| Hosting | [Netlify](https://www.netlify.com/) |

---

## ✨ Features
- ⚡ Fast static site built with Gatsby  
- 🎨 Responsive design for mobile, tablet, and desktop  
- 🧩 Modular SCSS structure for easy maintenance  
- 🗂️ Content managed via Netlify CMS  
- 🔍 SEO-friendly setup with meta tags and sitemap  
- 📬 Integrated contact form  

---

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/michfal/st_landing_page_v2.git
   cd st_landing_page_v2
   ```
2. **Install dependencies**

```bash
npm install
# or
yarn install
```
3. Run locally

```bash
npm run develop
# or
yarn develop
```
4. Build for production

```bash
npm run build
```
📂 Project Structure
```bash

st_landing_page_v2/
├── src/
│   ├── components/       # Reusable UI components
│   ├── pages/            # Gatsby pages
│   ├── styles/           # Global and modular SCSS
│   └── images/           # Assets

```

Deployed via Netlify — pushing to the main branch triggers automatic deployment.
